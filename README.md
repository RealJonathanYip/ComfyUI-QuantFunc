## About the plugin

ComfyUI-QuantFunc is the ComfyUI plugin for **QuantFunc**, a high-performance diffusion model inference engine. It runs quantized text-to-image and image-editing models with 2x–11x acceleration and no Python model dependencies.

Key features:

- Native C++/CUDA acceleration
- SVDQ offline quantization and Lighting runtime quantization
- LoRA support
- Text-to-image, image editing, ControlNet, and layered generation
- Runtime-quantized model export
