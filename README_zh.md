## 插件简介

ComfyUI-QuantFunc 是 **QuantFunc** 的 ComfyUI 插件，基于高性能扩散模型推理引擎，可用 2x–11x 加速运行量化文生图和图像编辑模型，无需 Python 模型依赖。

核心功能：

- 原生 C++/CUDA 加速
- SVDQ 离线量化与 Lighting 运行时量化
- LoRA 支持
- 文生图、图像编辑、ControlNet 和分层生成
- 运行时量化模型导出
